# Conventional Commits + gitmoji

Con `git.convencion = "conventional-gitmoji"`, el mensaje empieza por el emoji del tipo:

`<emoji> <tipo>(<ámbito>): <descripción>` → `🐛 fix(pagos): corregir la compensación duplicada`

| Tipo | Emoji | Significado |
|---|---|---|
| feat | ✨ | nueva funcionalidad |
| fix | 🐛 | corrección de un fallo |
| docs | 📝 | documentación |
| style | 🎨 | formato o estructura sin cambiar lógica |
| refactor | ♻️ | reestructurar código |
| perf | ⚡️ | rendimiento |
| test | ✅ | tests |
| build | 📦️ | build o dependencias |
| ci | 👷 | integración continua |
| chore | 🔧 | mantenimiento, configuración |
| revert | ⏪️ | revertir |
| (cambio incompatible) | 💥 | se añade además del `!` |
