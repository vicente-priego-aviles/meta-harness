# Tutorial

En este tutorial instalas **[meta-harness](../ayuda/glosario.md#meta-harness)** en **Spring PetClinic**, la aplicación de ejemplo oficial de Spring, y haces tu primer cambio con él, de principio a fin. Todas las salidas que verás son reales: el tutorial se ejecutó tal cual. Al terminar sabrás qué se instala, para qué sirve cada pieza y cómo trabaja el agente contigo.

## Lo que vas a conseguir
- El proyecto con su **[brain](../ayuda/glosario.md#brain)** (`brain/`), una [bóveda](../ayuda/glosario.md#boveda) de Obsidian versionada con el código.
- Claude Code **orientado** desde el primer mensaje de cada sesión: [carriles](../ayuda/glosario.md#carril) de trabajo, [riesgo](../ayuda/glosario.md#riesgo) y estilo.
- **Controles automáticos**: comandos peligrosos, riesgo de cada cambio, convención de commits, salida de Maven reducida.
- Un primer cambio con su **documento [FTD](../ayuda/glosario.md#ftd)**, sus pruebas y su evidencia.

> [!tip] Tiempo
> La instalación lleva unos minutos. El primer cambio depende de la tarea; elige algo pequeño y claro para esta primera vez.

> [!info] Si te pierdes con algún término
> FTD, [ASDD](../ayuda/glosario.md#asdd), brain, [hook](../ayuda/glosario.md#hook), riesgo… están todos en el [glosario](../ayuda/glosario.md).
